# E-Commerce-Product-Catalog

##  Overview

'MyStore' is a simple React-based web application that displays a collection of products in a clean and modern card layout.
It demonstrates the use of **React functional components, props, state, and hooks**.


## Features

* Display of multiple products in a grid layout
* Product ratings system
* Add to Cart functionality with cart counter
*  Navigation bar with logo
*  Responsive and aesthetic UI design
* Dynamic rendering using React state and props

## Technologies Used

* React.js
* JavaScript
* HTML & CSS
* VS Code

## Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/mystore.git
```

2. Navigate to the project folder:

```
cd mystore
```

3. Install dependencies:

```
npm install
```

4. Run the app:

```
npm start
```

5. Open in browser:

```
http://localhost:3000
```
